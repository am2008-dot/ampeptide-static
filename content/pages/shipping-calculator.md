## Shipping Cost Calculation Method

AMP Peptide shipping costs are calculated using a structured parcel-based logistics model that includes weight estimation, parcel splitting, destination pricing, and incremental weight adjustments.

> Example:
> 5 boxes → US → 1 parcel → weight 0.45kg → cost breakdown → final estimate

---

### 1. Weight Estimation Formula

Shipping weight is estimated based on order quantity:

```
If Quantity ≤ 5 boxes:Weight = 0.45 kgIf Quantity ≤ 10 boxes:Weight = 0.8 kgIf Quantity ≤ 30 boxes:Weight = 2.6 kgIf Quantity > 30 boxes:Weight = Quantity × 0.086 kg
```

This model reflects standard packaging density and scaling for larger shipments.

---

### 2. Parcel Splitting Rule

```
Maximum 30 boxes per parcel
```

Orders exceeding 30 boxes are automatically split into multiple parcels. Each parcel is calculated independently.

---

### 3. Base Shipping Cost by Destination

```
EU: 65 USD per parcelUS / MX: 90 USD per parcel
```

Handling fee:

```
+3 USD per parcel
```

---

### 4. Weight-Based Increment Calculation

```
If weight ≤ 0.5 kg:No additional costIf weight > 0.5 kg:Step size = 0.3 kgCost per step = 9 USD
```

Formula:

```
Steps = ceil((Weight - 0.5) / 0.3)Parcel Cost =Base Cost + Handling Fee + (Steps × 9)
```

---

### 5. Total Shipping Cost

```
Total Cost = Sum of all parcel costs
```

Each parcel is calculated separately and then aggregated into the final result.

---

### 6. Calculation Logic Summary

- Tier-based weight estimation
- Fixed maximum parcel size (30 boxes)
- Destination-based base pricing
- Step-based weight increment model
- Multi-parcel aggregation system
