使用说明

· 页面管理 / 博客文章：左侧列表点击即编辑，修改后点「保存修改」，网站会在 1–2 分钟内自动重新部署生效。

· 站点设置：导航菜单、首页横幅、首页栏目图片、联系方式等全局配置都在这里（JSON 格式）。

· 媒体库：上传图片后复制图片地址，可粘贴到任意文章的 image 字段或正文中。

· 所有修改都会提交到 GitHub 仓库 am2008-dot/amppeptide-static，可随时在 GitHub 上查看历史、回滚。
